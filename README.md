# Falls View Camp Digital

"Generate a responsive, multi-page eco-tourism website for 'Falls View Camp', a mountain campsite and farm-to-table cafe in Sergio Osmeña. The aesthetic should be rugged but inviting, featuring deep forest greens, earthy wood tones, and white/azure accents to represent waterfalls.

Please include the following architecture:

Home: A hero section with a placeholder for a panoramic mountain and waterfall view. Include a prominent 'Book a Stay' call-to-action button.

Accommodations (Interactive): A selection screen layout where users can toggle between 'Native Cottages', 'Cabins', and 'Tent Pitching'. Include placeholder pricing, capacity details, and a 'Check Availability' form (Name, Dates, Guests).

Farm-to-Table Cafe: A visually clean menu section highlighting all-day breakfast, signature coffee mixes, and ingredients sourced directly from their backyard farm.

Explore & Activities: A grid layout showcasing activities like waterfall trekking and farm tours.

Ensure the UI feels modern, heavily utilizes cards for the accommodation options, and includes clear, distinct states for buttons and form fields."
